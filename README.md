# Arnie Arcuino — Full-Stack Web Developer Portfolio & Wireframe Graph

Modern, responsive portfolio website and interactive Figma-style wireframe graph for **Arnie Arcuino**, Full-Stack Web Developer based in **Brgy Tambulilid, Ormoc City, Leyte**.

---

## 🚀 Live Site & Deliverables

* **`index.html` / `portfolio.html`** — Full-Stack Developer Portfolio website with dark/light mode, filterable project gallery, and interactive case study modal.
* **`wireframe.html`** — Interactive Figma-style Wireframe Graph canvas with real-time SVG connectors, draggable artboards, pan/zoom engine, and screen index.
* **`ui_canvas.html`** — UI Design System & Component Canvas featuring design tokens and color swatches.
* **`assets/`** — Project media assets (Live Stage Drummer photo from Camp 2026 Baybay & Gatekeepers Gospel Ministry typographic banner).

---

* **Stage Magenta Glow (`#EC4899` / `#D946EF`)** — Dynamic lighting & pulse glows
* **Celestial Purple (`#8B5CF6`)** — Secondary gradient tones
